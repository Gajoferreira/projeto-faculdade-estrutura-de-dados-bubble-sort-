# projeto-faculdade-estrutura-de-dados-bubble-sort-
O código gera 20 números aleatórios entre 1 e 500, sem repetir nenhum número. Depois, ele faz uma cópia dos números originais e mostra o vetor na tela. Em seguida, utiliza o método Bubble Sort para organizar os números do menor para o maior. No final, mostra o vetor ordenado e a cópia com os números na ordem em que foram gerados.
